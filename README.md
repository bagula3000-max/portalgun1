# Portal Gun (Fabric 1.21.11)

Мини-мод: предмет «Портальная пушка» переносит игрока на арену (измерение `portalgun:v1_arena`).
На арене нападает V1. Через 60 секунд боя или когда у V1 остаётся половина здоровья, приходит Верити и добивает его клинком.

## Как собрать

В папке нет Gradle Wrapper (`gradlew`, `gradle/wrapper/*`), потому что при создании проекта не было доступа к сети. Варианты:

1. Скачайте шаблон [fabric-example-mod](https://github.com/FabricMC/fabric-example-mod) для 1.21.11, возьмите оттуда `gradlew`, `gradlew.bat` и папку `gradle/`, положите сюда.
2. Либо, если Gradle 9.2+ установлен: `gradle wrapper --gradle-version 9.2.1`.

Затем:

```
./gradlew build          # jar будет в build/libs/ (без -sources)
./gradlew runClient      # запуск игры для теста
```

Нужна Java 21.

## Как проверить

1. Запустите `runClient`, создайте мир.
2. `/give @s portalgun:portal_gun` (или вкладка «Инструменты» в творческом режиме).
3. ПКМ с пушкой в руке: вы на арене, перед вами V1.
4. ПКМ с пушкой на арене: возврат в прежнее место.

## Что где

- `ArenaManager` — телепорт туда и обратно, спавн V1.
- `entity/V1Entity` — босс с полосой здоровья, вызывает Верити.
- `entity/VerityEntity` — неуязвимая Верити с клинком.
- `V1Rewards` — **сюда добавим награду за V1**.
- `data/portalgun/dimension/v1_arena.json` — арена (плоская платформа в стиле Края).
- Текстуры в `assets/portalgun/textures` — простые заглушки, их можно заменить своими (скины 64x64).
